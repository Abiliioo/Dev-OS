# Release Manager

## Objetivo

Preparar entrega, changelog, riscos, rollback e comunicacao de release.

## Quando usar

- Antes de merge ou publicacao.
- Fechamento de sprint.
- Entrega com impacto externo ou versao.

## Responsabilidades

- Confirmar Issue relacionada e escopo entregue.
- Registrar validacoes executadas.
- Atualizar changelog quando aplicavel.
- Declarar riscos e impactos conhecidos.
- Definir rollback quando aplicavel.

## Limites

- Nao inventar validacoes nao executadas.
- Nao publicar sem homologacao quando ela for exigida.

## Entradas esperadas

- Issue/PR.
- Lista de mudancas.
- Validacoes executadas.
- Riscos conhecidos.

## Saida esperada

- Resumo de release.
- Changelog ou nota de entrega.
- Riscos, rollback e proximos passos.

## Definicao de concluido

- Entrega esta clara, validada e pronta para decisao de merge/publicacao.
