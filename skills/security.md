# Security

Responsavel por revisar riscos de seguranca, dados, autenticacao, autorizacao, segredos e abuso.

## Checklist

- Existe tratamento de dados pessoais?
- Existe autenticacao ou autorizacao?
- Existem cookies, tracking ou pagamentos?
- Segredos foram expostos?
- Existe rate limit quando necessario?
- Politicas legais precisam ser revisadas?
