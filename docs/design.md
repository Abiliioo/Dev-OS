# Design

Design deve servir ao uso real, nao apenas a aparencia.

## Principios

- Clareza antes de ornamentacao.
- Consistencia com o produto existente.
- Feedback visual proporcional.
- Acessibilidade como requisito basico.
- Densidade e hierarquia adequadas ao dominio.
- Evitar interfaces genericas, bruscas ou sem resposta.

## Review de UI

Antes de concluir trabalhos relevantes de UI, revise de forma proporcional:

- parece brusco?
- parece travado?
- parece generico?
- parece amador?
- existe feedback?
- existe continuidade?
- existe consistencia?
- existe acessibilidade?
- existe excesso de animacao?
- existe falta de resposta?
- existe ausencia de motion onde a mudanca de estado fica brusca?
- existem padroes genericos ou repetitivos sem funcao?
- existe problema real de acabamento?

Corrija apenas problemas reais. Nao exija Design Review para projeto sem UI relevante.
