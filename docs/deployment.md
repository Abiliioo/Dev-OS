# Deployment

Deploy deve ser previsivel e reversivel quando possivel.

## Antes do deploy

- Confirme escopo entregue.
- Confira validacoes executadas.
- Revise riscos conhecidos.
- Revise impactos legais quando houver dados, cookies, tracking, pagamentos ou autenticacao.
- Tenha plano de rollback quando aplicavel.

## Depois do deploy

- Execute smoke test.
- Monitore erros relevantes.
- Registre incidentes ou follow-ups.
- Atualize changelog quando a entrega alterar comportamento relevante.
