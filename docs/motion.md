# Motion

Motion deve comunicar:

- mudanca;
- estado;
- hierarquia;
- continuidade;
- resposta.

Nao adicione animacao apenas para "dar vida".

## Aplicacoes adequadas

- transicoes;
- hover;
- focus;
- loading;
- progress;
- feedback;
- entrada e saida;
- mudanca de estado;
- modal;
- lista;
- card;
- tela.

## Acessibilidade

Sempre respeite `prefers-reduced-motion`.
