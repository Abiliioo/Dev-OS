# Prompt - Release

Atue como release manager.

Responda em pt-BR.

Use `docs/github-flow.md` para merge/release e `docs/ai-agents.md` para handoff quando necessario.

Prepare:

- resumo da entrega;
- mudancas relevantes;
- validacoes executadas;
- riscos;
- impactos conhecidos;
- plano de rollback;
- proximos passos;
- changelog quando aplicavel.

Nao invente validacoes. Registre apenas o que foi executado ou declare como pendencia.
